# 系統性品質升級報告（2026-10-31）

## 實際改動

1. 保留既有儲存格式與 22 套戰術，新增可選 Scene v2。動畫引擎拆為幾何、型別、絕對時間取樣與共用時鐘。
2. 以十名球員的獨立多段軌跡重新編排 PnR。中鋒接觸掩護前上提，定住到持球者利用掩護後才順下；Slip 分支刻意提早離開。防守者繞行、交換責任、延阻回收或包夾。
3. Drop / Switch / Hedge / Blitz 均有不同 d1 / d5 路線；弱側 Low Man 與 Nail 協防獨立移動。Hedge / Blitz 依防守回收前的窗口提早出球，解說與事件時間一致。
4. BallEvent 將出球、飛行、接球與投籃分開。球員、球、陰影、路線、區域、標註與步驟取樣同一時間。暫停停止 RAF；Seek 不依賴之前播到哪裡。
5. 改為球衣與肢體標記，呈現轉向、步伐、掩護、傳球與接球姿態。進攻跑位、運球、傳球與防守輪轉使用不同線型；路徑按執行進度逐步顯示。
6. 核對 NBA 尺寸，修正三分線交點、罰球區與合理衝撞區。每個球場使用獨立 SVG ID。鏡頭與拖曳共同使用逆矩陣，修正縮放／翻轉後定位錯誤。
7. 三欄工作區與共用設計 token；左右可收合。深色／木地板、斜角、跟隨、聚焦、連續縮放皆實際可操作。右側補齊站位、發動者、逐人任務、反應與破解、成功條件及失敗原因。
8. 專業時間軸新增步驟章節、1/60 秒逐格、自訂速度與循環。比較時間軸取兩側最大長度，解決較長右側不能播完的問題。

## 驗證結果

- TypeScript `tsc -b` 通過。
- 正式 Vite build 通過。
- Vitest 18 / 18 通過。
- Playwright 10 / 10 通過，包含所有原有測試。
- 24 種攻防組合以 60Hz 掃描每名球員兩兩間距，中心距離不小於 1.7ft；測試曾抓出相交後已修正路徑與時序，沒有降低門檻規避問題。
- 逐畫格位移、曲線非直線性、掩護停頓、四防守座標差異、傳接球同步與循環均有單元測試。
- 桌面 1440px、手機 390px 與平板 768px 操作／版面檢查；手機與平板沒有頁面橫向溢出。
- UI 靜態檢查器沒有回報機械規則問題。

## 剩餘限制

其他 21 套戰術還沒有逐套達到這套 PnR 的手工編排深度。防守屬教學劇本，非通用自動防守系統。球員間距檢查不是完整物理碰撞引擎，也不套用到任意使用者編輯內容。向量球衣與斜角投影仍是 2D。舊編輯器保留，但進階 Scene 複製後轉成取樣畫格，尚不能直接編輯 Catmull–Rom 控制點與精細傳球事件。真實 NBA 球員、賽事重建及 Safari / 行動裝置實機驗證不在已完成項目中。
