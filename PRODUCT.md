# NBA Tactics Lab
## Platform
Web, Traditional Chinese. Desktop, tablet, mobile.
## Stack
User specified React, TypeScript, Vite, Tailwind, SVG, Motion, Zustand and Lucide. Local JSON and localStorage, no backend. GitHub Pages deployment.
## Product truth
Educational NBA-style tactical simulations, explicitly not real-game reconstructions. Synchronized 10-player animation, step explanations, editing and comparison. The supplied brief specifies a dark three-column analysis workspace with wood court.
